# Blinding Rules (Template — Specification Only)

## Evaluators must not see
model · provider · attempt number · production designation · reference class
(gold/silver/bronze) · prompt version · condition identity · PS-03 scores.

## Presentation
Source + candidate only (reference only under an explicitly labeled condition).
Pairwise: "A"/"B" with randomized order; identity hidden.

## Deviation
If blinding cannot be achieved, record a `BLINDING_FAILURE` deviation, estimate impact,
and do not claim "fully blinded".
