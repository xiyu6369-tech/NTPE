# NTPE Documentation Center

This directory is the official documentation center for NTPE.

## Structure

- `architecture/` — system architecture and design principles
- `developer/` — contributor and development workflow notes
- `api/` — API and integration notes
- `enterprise/` — enterprise deployment documentation
- `deployment/` — deployment runtime and operations documents
- `release/` — stable, LTS, and professional release notes
- `roadmap/` — version roadmap documents
- `migration/` — migration notes and compatibility guides
- `freeze/` — freeze records for stable baselines
- `changelog/` — stage-level and version-level change history
- `stages/` — Stage documentation organized by release phase

## Root Directory Policy

The project root should keep only essential project entry files. Stage READMEs, release records, freeze notes, and long-form design notes should be placed in `docs/`.
