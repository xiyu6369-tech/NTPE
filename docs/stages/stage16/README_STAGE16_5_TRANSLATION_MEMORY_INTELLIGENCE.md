Stage-16.5 adds a high-level Translation Memory Intelligence layer for exact/fuzzy source-target reuse, context-aware scoring, terminology-aware matching, character-aware matching, and JSON import/export.

The layer is additive and keeps Foundation v1.0, NTPE 1.1 LTS, Stage-14 Provider Framework, and Stage-15 Translation Quality Engine frozen contracts intact.
