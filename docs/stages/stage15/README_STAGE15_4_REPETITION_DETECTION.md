# NTPE 1.2 Professional - Stage-15.4 Repetition / Duplicate Content Detection

Stage-15.4 adds deterministic duplicate-content analysis to the Translation Quality Engine.

## Scope

- Exact duplicate paragraph detection
- Exact duplicate sentence detection
- Adjacent near-duplicate paragraph detection
- Repeated n-gram detection
- Quality rule integration
- JSON and text report output

## Compatibility

This stage only adds `core.quality` modules. It does not modify Foundation v1.0, NTPE 1.1 LTS Frozen, Stage-14 Provider Framework Freeze, or public Stage-15.1 to Stage-15.3 APIs.
