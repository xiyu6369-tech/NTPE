# NTPE 1.2 Professional - Stage-17.2 Job Scheduler / Batch Task Manager

Stage-17.2 adds the production batch scheduling layer for Translation Workflow Engine.

Included components:

- JobScheduler
- JobQueue
- JobWorker
- JobPriority
- JobState
- JobResult
- JobEventBus
- Job metrics
- Workflow Engine binding

Compatibility rules:

- Stage-17.1 Workflow Engine APIs remain unchanged.
- Stage-16 Advanced Translation Intelligence remains frozen.
- Stage-15 Translation Quality Engine remains frozen.
- Stage-14 Provider Framework remains frozen.
