# PS-04.1 Regression Timeout & Encoding Hotfix

Fixes two issues found during Golden Set validation:

- Literary regression used the NVIDIA client default 60-second read timeout unless the shell environment was set correctly.
- Timeout errors contained non-ASCII guidance, which could become mojibake in Windows report files.
- CLI now accepts set aliases: `golden`, `Golden_Set`, `smoke`, `regression`.

Recommended command:

```bat
python launcher_translate.py regression --set golden --stage PS-04 --profile literary --api-timeout 180 --overwrite
```
