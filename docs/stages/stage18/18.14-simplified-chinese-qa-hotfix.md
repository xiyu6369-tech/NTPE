# Stage-18.14 Simplified Chinese QA Hotfix

This hotfix changes the production translator behavior so remaining simplified-Chinese detections after Taiwan-Traditional normalization are recorded as metrics/warnings by default instead of failing the whole file.

## Why

Real translation testing showed chunks could finish provider calls successfully but fail the batch because one remaining simplified-Chinese hit was treated as a hard QA failure. This blocked translation output even though the formatter had already normalized most text.

## Behavior

- Default policy: `normalize`
- CLI option: `--simplified-chinese-policy normalize|warn|fail`
- Environment override: `NTPE_SIMPLIFIED_CHINESE_POLICY`
- Metrics still report `simplified_hits`
- Strict failure remains available through `fail`
