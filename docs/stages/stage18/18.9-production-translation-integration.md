# Stage-18.9 Production Translation Integration

This stage adds the official production translation entry for NTPE 1.2 Professional.

## Official command

```bat
set NVIDIA_API_KEY=your_key
python launcher_translate.py batch input output
```

Single TXT:

```bat
python launcher_translate.py txt input\novel.txt output
```

Environment check:

```bat
python launcher_translate.py doctor
```

Dry run without calling NVIDIA API:

```bat
python launcher_translate.py txt input\novel.txt output --dry-run
```

## Notes

- This stage does not modify Foundation v1.0 or NTPE 1.1 LTS frozen behavior.
- The launcher delegates to the existing TranslationRuntime and LTS TXT/Batch runtime.
- `input/` and `output/` are created as standard production folders.
