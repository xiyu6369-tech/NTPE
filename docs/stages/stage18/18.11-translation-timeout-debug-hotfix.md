# Stage-18.11 Translation Timeout & Debug Hotfix

Adds fail-fast NVIDIA request timeout handling and optional debug output for production translation.

Environment variables:

- `NTPE_API_TIMEOUT`: read timeout seconds, default `60`
- `NTPE_API_CONNECT_TIMEOUT`: connect timeout seconds, default `10`
- `NTPE_TRANSLATE_DEBUG`: set to `1` to show request/response progress

This stage does not modify frozen Foundation or LTS contracts.
