# Stage-18.12 Translation Name Lock Hotfix

This hotfix stabilizes production translator name locking.

## Changes

- Adds post-translation alias correction for locked glossary terms.
- Corrects common wrong variants of `정태의 -> 鄭泰義`, including `定泰義`.
- Adds explicit prompt-level blocked-alias instructions.
- Keeps Foundation v1.0 and NTPE 1.1 LTS frozen behavior backward compatible.
