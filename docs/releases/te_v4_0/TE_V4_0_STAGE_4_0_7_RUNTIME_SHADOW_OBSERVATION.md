# TE v4.0 Stage-4.0.7 Runtime Shadow Observation

Adds a disabled-by-default shadow observer for supplied Runtime event metadata.

When enabled, it:
- observes outcomes, provider/model usage, retries, latency, and provider_attempts=0
- runs the analysis-only reliability adapter
- returns non-executable recommendations

It does not modify Runtime behavior or execute any recovery action.
