NTPE 1.1 LTS Stable Release Preparation
========================================

Run:

    python ntpe_lts_stable_preparation.py

Purpose:

- Validate RC-06 freeze readiness.
- Prepare NTPE 1.1 LTS Stable release metadata.
- Generate stable preparation manifest, hash, and report.
- Confirm clean packaging policy before Full ZIP generation.

This stage does not change translation behavior and makes no external API calls.
